# Ransomware-Prevention-Checklist
study ransomware attack lifecycle at a conceptual level and identify defensive control


## Objective
Understand ransomware risks, its basic attack lifecycle, and key defensive controls.

## What is Ransomware?
Ransomware is malware that locks or encrypts files and demands a ransom to restore access.

## Basic Attack Lifecycle
1. Initial Access
2. Execution & Spread
3. Privilege Escalation
4. Data Discovery
5. Encryption & Disruption
6. Extortion
7. Recovery

## Prevention Controls

- Backups : Maintain regular, protected backups and test restoration.
- Patching : Keep operating systems and applications updated.
- MFA : Use multi-factor authentication to protect accounts.
- **Least Privilege : Give users only the permissions they need.
- User Awareness : Train employees to identify phishing and suspicious files.
- Monitoring : Detect unusual account, file, and system activity.

## Interview Questions

What is ransomware ?
Malware that encrypts or blocks access to data and demands a ransom.

Why are backups important ?  
They allow organizations to recover data after an attack.

What is least privilege ?
Giving users only the minimum permissions required for their work.

## conclusion
ackups + Patching + MFA + Least Privilege = Stronger Ransomware Protection
